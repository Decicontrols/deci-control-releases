# Deci Control – Downloads und Updates

Dieses Repository enthält nur die veröffentlichten Installationspakete von **Deci Control** (Deci Controls).
Deci Control lädt Updates automatisch von hier (GitHub Releases, Kanal `stable`).

- Installer: jeweils `DeciControl-win-Setup.exe` im neuesten Release.
- Vorab-/Test-Versionen sind als „Pre-release“ markiert und werden normalen Installationen nicht angeboten.

Kein Quellcode, keine Nutzerdaten.
